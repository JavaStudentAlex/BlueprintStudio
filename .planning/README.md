# BlueprintStudio GSD Planning

This directory is the GSD planning surface for BlueprintStudio.

Start here:

- `PROJECT.md` - product context, core value, constraints, and decisions.
- `REQUIREMENTS.md` - checkable product requirements and traceability.
- `ROADMAP.md` - milestone and phase structure.
- `STATE.md` - current status, worker policy, and next-action guidance.
- `todos/AGENT-TASKS.md` - GSD-native task queue.
- `intel/SOURCE-MIGRATION.md` - source document migration map.

Legacy Jules/Codex planning files, task manifests, validators, and source
snapshots were removed after their content was transferred into this GSD
structure. Jules automation workflows remain available only as GSD-compatible
bridges that read `.planning/`.
